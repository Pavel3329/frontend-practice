# Frontend Practice

A collection of 11 frontend practice projects developed during my web development training.

This repository brings together small, independent exercises focused on **HTML, CSS, JavaScript, DOM manipulation, asynchronous programming, and API integration**.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Git & GitHub

## Repository Structure

Each project is located in its own directory and contains its own HTML, CSS, and JavaScript files.

The projects are independent and can be explored individually.

## Getting Started

1. Clone the repository:

   `git clone https://github.com/Pavel3329/frontend-practice.git`

2. Open the project directory of your choice.

3. Open its `index.html` file in a browser.

Some projects may require an HTTP development server for API-related functionality.

## Git History

The projects were originally developed in separate Git repositories and later consolidated into this monorepository using `git subtree`, preserving their Git commit histories.

## Purpose

This repository documents my progress in frontend development, from basic UI components and forms to interactive JavaScript applications and asynchronous operations.
